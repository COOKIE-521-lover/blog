A U B =“A、B之间至少发生一个”
```
P（A U B）= P（A）+ P（B）- P（AB）；
```
两个及三个以上：
```
P（AUBUC）=P（A）+ P（B）+ P（C）- P（AB）- P（BC）- P（AC）+ P（ABC）
```
“ABC至少发生一个 = P（AUBUC）”

奇数前+，偶数前-

```
P(A-B)=P（A）- P（AB）

对立事件：P（A拔）= 1- P（AB）
```
条件概率：b发生的条件下，a发生的概率
```
P（A | B）= P（AB）/ P（B）
```
a发生且b不发生的概率=a概率-ab概率
```
P（A·B拔）= P（A）- P（AB）
```
